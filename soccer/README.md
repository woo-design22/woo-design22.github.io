# 반대항축구 — 실행·인수인계 안내

기준일: 2026-10-08. 현재 작업 사본은 GitHub 공개 원본을 새로 복제한 저장소의 `codex/soccer-handoff` 브랜치다. 원본 백업은 수정하지 않았다. 원본 복구 뒤 보완한 기능과 운영 절차를 이 사본에서 관리한다. 공개 반영 기록은 최신 HANDOFF를 본다.

## 실행

- 혼자 하기: `index.html`을 브라우저에서 연다. 서버·로그인이 필요 없다.
- 내 PC 온라인 테스트: `server/내 PC에서 실행.cmd`를 두 번 누르고 `http://127.0.0.1:8080/`을 연다. 두 탭으로 두 사람이 들어갈 수 있다.
- 외부 사람과 온라인: 최초 한 번 `server/GitHub 로그인.cmd`로 기존 게시판을 소유한 계정에 로그인한 다음 `server/온라인 켜기.cmd`를 실행한다. 출력된 주소에서 접속한다. 실행 중인 PC를 켜 둔다. 종료하려면 `server/온라인 끄기.cmd`를 실행한다.
- 이미 GitHub Pages에 공개된 사본은 별도 Git 반영·배포가 필요하다. 로컬 실행만으로 공개 사본이 갱신되지는 않는다.

서버 요구사항은 Node.js 22 이상과 `ws`다. 이 작업 사본에는 `npm ci --ignore-scripts`로 설치했다. Cloudflare와 GitHub CLI도 이 PC에 설치돼 있다. 실행기는 설치, 로그인, Gist 소유자, 서버 버전을 검사한다. 종료 시 자신이 시작한 서버·터널을 정리한다.

서버 포트는 `PORT`(기본 8080), 수신 주소는 `HOST`(기본 127.0.0.1)로 변경한다. 기본값은 로컬 전용이며 Cloudflare 터널이 외부 접속을 전달한다. 다른 프로그램이나 이전 빌드가 포트를 차지하면 종료하고 다시 시작한다. 실행 로그 경로는 실패 안내에 표시된다.

## 현재 동작

- 캐릭터 9종, 경기장 4종, 공 3종, 최대 20명, 코어 60Hz, 프로토콜 20.
- 기본 전후반 각 90초, 동점이면 30초씩 연장. 혼자 하기는 AI, 온라인 빈자리는 사람을 기다린다.
- 방 생성 시 1~12반 번호를 정한다. 정원·양 팀 인원·전원 준비 조건을 만족해야 방장이 시작할 수 있다.
- 진행 중 경기의 빈자리로 참가할 수 있다. 보존 중인 재접속 자리는 빈자리로 취급하지 않는다.
- 예기치 않게 연결이 끊기면 15초 동안 팀·선수·방장 권한을 보존한다. 같은 탭은 자동 복귀를 시도한다. 복귀도 지연 검사를 거치며 토큰은 새로 발급한다.
- 명시적으로 나가거나 정상 종료·강퇴된 연결은 보존하지 않는다. 서버 재시작·15초 경과 뒤에는 기존 경기 복귀가 불가능하다. 토큰은 서버별·탭별 sessionStorage에 저장한다.
- 휴대폰은 조이스틱을 끝까지 밀어 달린다. PC는 Shift. 슛 D, 드리블 W, 방귀 S, 감아차기 Q/E, 패스 Z, 필살기 A.

## 공개 파일과 설정

HTTP 서버는 `index.html`, `game-core.js`, `sprites.js`, `chars/*.png`, 상태 점검용 `/stats`만 제공한다. `server/`·문서·패키지·설정 파일은 요청해도 404다. 잘못된 URL은 400으로 끝나며 서버를 중단시키지 않는다.

서버 주소 게시판은 Gist `5d0b2f4daf7e089553c5a541b53cd29c`의 `soccer-server.json`이다. 프런트의 `GIST_ID`와 실행기의 `$gistId`를 함께 유지한다. 예전 Deno 게시판은 기본 비활성화했으며 백업의 `registry.txt`와 비밀키는 복사하지 않았다. 예전 Deno를 재사용하려면 해당 서비스에서 쓰기 키를 먼저 교체해야 한다.

회원 계정·DB가 없으므로 프로세스를 종료하면 방과 경기가 초기화된다. IP당 제한은 직접 연결 주소를 기준으로 하며 터널 뒤 실제 사용자별 제한은 별도 구현이 필요하다.

## 검증 명령

`server` 폴더에서:

```powershell
npm test
npm run regress
npm run loadtest -- --port 8080 --rooms 5 --players 20 --seconds 300
powershell -NoProfile -ExecutionPolicy Bypass -File start-online.ps1 -LocalOnly -CheckOnly
```

브라우저 검사는 서버를 띄운 뒤 `soccer` 폴더에서 `node tools/handoff-browser.js 8080`을 실행한다. Chrome 설치 경로를 사용하는 개발용 검사이며 실제 휴대폰 검사와는 다르다. 스크린샷과 결과는 `verification/`에 남는다. 보안·재접속 통합 검사는 별도 로컬 서버를 자동으로 켰다가 종료한다.

`loadtest.js --rooms N`은 N개 방을 **동시에** 실행한다. 이전 버전은 방을 순서대로 검사했다. 실패는 0이 아닌 종료 코드로 반환한다. `regress.js`는 인자 없이 현재 코어를 측정하며 선택적으로 비교할 코어 파일의 절대 경로를 받는다.
