  - 장례(서울 61곳): 품목 평균 167개. 서울아산 3일장 기본 시나리오 13,964,400원 = 빈소248㎡ 201만×3 + 안치 8.88만×3 + 염습 45만 + 제단6호 180만 + 도우미 15만×3 + 청소 5.6만×3 + 관 10만 + 수의 20만 + 식사 150명×3만.

- 데이터 수집에서 배운 것 (다음 수집 시 필수):
  - 두 사이트 모두 **세션 쿠키 없으면 AJAX 무응답**(타임아웃) → `warm_up()` 먼저. 비브라우저 UA도 끊김 → 브라우저형 UA + 식별자.
