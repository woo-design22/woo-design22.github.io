## 1. 먼저 할 일 (순서대로)

### ① 서울 열린데이터광장 인증키 — 오늘 바로

<https://data.seoul.go.kr> → 회원가입 → 「인증키 신청」. **즉시 발급된다.**
한 키로 광장의 모든 서비스를 쓴다.

사양서 M1-2가 「역별승하차인원 일일 수집」을 1순위로 둔 이유는 *오늘 안 받으면 사라지는 데이터*라서다.
그런데 공공데이터포털 쪽은 승인에 며칠 걸린다 — 그 며칠이 그대로 손실이다.
그래서 **즉시 발급되는 이쪽부터 붙여 축적을 시작한다**(DECISIONS.md D-09).

받은 뒤:
```bash
python pipeline/collect_subway_daily.py --probe
```

### ② 공공데이터포털 계정 + 활용신청

<https://www.data.go.kr> → 회원가입 → 아래 넷을 각각 활용신청.

| 서비스 | 쓰임 |
|---|---|
| 서울교통공사_역별승하차인원 | **최근 1주일치만** — 일일 크론의 본체 |
| 서울교통공사_지하철혼잡도정보 | 착석 확률의 기준(34% = 좌석 만석). 파일, 분기별 |
| 서울교통공사_열차시간표 | 역간 소요시간 실측 |
| 특일정보(공휴일) | 요일 구분(평일/토/일·공휴일) |

**승인되면 서비스 상세 화면에서 「엔드포인트」와 「샘플 URL」을 그대로 복사해**
`pipeline/config.json`의 해당 `url`에 넣는다. **추측해서 적지 말 것** — 틀린 주소는 오류를 내지 않고
빈 응답을 주는 경우가 많아, 크론이 몇 주 돌고 나서야 아무것도 안 쌓였다는 걸 알게 된다.

**운영계정 전환도 같이 신청한다**(사양서 4.4). 개발계정은 1,000건/일이라 하루치 수집도 빠듯하다.
활용사례 등록 후 증량 신청이고 승인에 며칠 걸리므로 **착수 즉시** 낸다.

### ③ T-DATA (TAIMS) 인증키

<https://t-data.seoul.go.kr> → 회원가입 → API 활용신청.
이 프로젝트에서 가장 중요한 원천이다(아래 3절).

받은 뒤:
```bash
python pipeline/fetch_tdata_section.py --probe
```
`--probe`는 응답의 **실제 필드 이름**을 찍는다. 사양서 4.2의 표기와 다르면
`pipeline/parse_tdata.py`의 `FIELD_ALIASES`·`HOUR_PATTERNS`에 별칭을 더한다.

### ④ 서울시 미래첨단교통과에 문의 (사양서 4.4)

> **환승 승차가 승차인원에 합산됩니까?**

재차인원 계산에 직결된다. 합산된다면 환승역·환승 정류장에서 승차량이 부풀려져 있고,
그대로 쓰면 그 구간의 재차인원이 과대평가된다. 답을 받으면 DECISIONS.md에 적는다.

(54/160 = 33.75%). **두 값을 따로 고치면 임계값이 깨진다** — 단위 테스트가 이를 검사한다.

```
http://t-data.seoul.go.kr/apig/apiman-gateway/tapi/TaimsTpssA18RouteSection/1.0
요청: apikey, stdrDe(YYYYMMDD), startRow, rowCnt
```

| 필드 | 의미 |
|---|---|
| `route_id`, `from_sta_id`, `to_sta_id`, `sta_sn` | 노선·구간·정류장 순서 |
| `a18Num00h` ~ `a18Num23h` | 시간대별 **평균 재차인원** |
| `max_a18Num00h` ~ `max_a18Num23h` | 시간대별 **최대 재차인원** |
| `a18FcntNum00h` ~ `23h` | 시간대별 운행횟수 |
| `a18OverCntNum00h` ~ `23h` | 시간대별 용량초과 운행횟수 |

**평균·최대·운행횟수가 함께 온다는 것이 이 프로젝트의 결정적 이점이다.**
셋으로 분포의 표준편차를 역산한다(Blom 근사, `common.sd_from_mean_max`).
평균만 쓰면 「8대 중 3대는 만원」이 통째로 사라진다.

라이선스 **저작자표시(BY)** — 2차적 저작물 작성 포함 자유이용, 상업적 이용 가능.

**요일 처리**: 일자별로만 오고 평일/토/일 구분값이 없다. 최소 8주치를 모아
날짜를 요일로 바꿔 집계한다(`--backfill`). 공휴일은 일요일 프로파일로 취급하므로
`data/holidays.json`이 먼저 채워져 있어야 한다.

## 4. 실시간 보정

`서울특별시_버스도착정보조회`:

- `brerde_Div1` = 재차 구분 (`0` 데이터없음 / `2` 재차인원 / `4` 혼잡도)
- `brdrde_Num1` = 구분이 `2`면 재차인원(광역버스 `routeType=6`이면 잔여좌석수),
  `4`면 혼잡도 3단계(`3` 여유 / `4` 보통 / `5` 혼잡)

**일반 시내버스는 3단계뿐이고 광역버스만 잔여좌석수를 준다.**
통계로 기저 확률을 만들고 실시간으로 ± 보정하는 2단 구조로 간다.
UI에는 예측치임을 밝힌다(사양서 11장).

## 5. 주의사항 (사양서 4.4)

- **현금 승하차는 집계되지 않는다.** 교통카드 기준. 서울은 현금 비율 1% 안팎이라 실무상 무시.
- **환승 승차 합산 여부는 확인 전이다.** 위 ④ 참고.
- **공공데이터포털 개발계정은 1,000건/일.** 운영계정 전환을 착수 즉시 신청한다.

## 6. 파일이 놓이는 자리

```
data/
  raw/subway/<소스>/<YYYYMMDD>.json   원천 응답 그대로 (가공 없음, 커밋 안 함)
  raw/subway/index.json               어느 날짜를 받았는지의 대장
  raw/tdata/<YYYYMMDD>.json           T-DATA 하루치 원천
  holidays.json                       공휴일 표 (요일 구분에 쓰임)
  routes/<routeId>.json               집계본 — 구간·요일·시간대별 {mean, sd, trips, over}
  routes/index.json                   노선 목록
  subway/congestion.json              지하철 혼잡도 격자 (있으면 검증이 REAL 모드로 돈다)
  logs/YYYYMM.log                     수집 로그
```

`data/subway/congestion.json`의 서식 — 검증 테스트가 이 모양을 읽는다:

```json
{
  "slotMinutes": 30,
  "startMinutes": 300,
  "grid": {
    "6|월곡|weekday": [12.4, 15.1, "...30분 간격 혼잡도(%)..."],
    "6|월곡|saturday": ["..."],
    "5|전체|weekday": ["..."]
  }
}
```

이 파일이 생기는 순간 `node --test tests/*.test.js`가 SIM에서 **REAL**로 바뀌고,
사양서 10장의 기준을 실측에 대고 검사한다.

## 버스 혼잡도 3단계의 공식 의미 — 재보정(D-65)의 기준선

버스위치 API(`getBusPosByRtid`)의 `congetion`(3 여유 · 4 보통 · 5 혼잡 · 0 미제공)은
서울시가 2015년 국내 최초로 시작한 혼잡도 안내의 단계다. **공식 정의가 곧 좌석 기준이다**
(서울시 보도자료, news.seoul.go.kr/traffic/archives/33643):

| 단계 | 공식 정의 | 앉을 자리로 읽으면 |
|---|---|---|
| **여유(3)** | **「좌석에 앉을 수 있는 정도」** | 빈 좌석 있음 → 탈 때 앉음 |
| 보통(4) | 「입석 승객이 손잡이를 하나씩 잡고 서 있을 수 있는 정도」 | 좌석 만석 → 탈 때 못 앉음 |
| 혼잡(5) | 「통로까지 서고 입석끼리 몸이 맞닿는 정도(이상)」 | 완전 입석 |

- 산출: 교통카드 승·하차 재차인원 기준, **차종 크기(대형 11m / 중형 9m) 반영**. 오차 약 1~2명.
- 숫자 경계(재차 몇 명에서 갈리는지)는 비공개 — 정성 정의만 공표.
- 대상: 입석형(간선·지선·순환)만. **광역·마을버스는 미제공**(수집 실측과 일치 — 마을버스 전부 0).
- 따라서 재보정에서 「탈 때 앉을 확률」의 실측 상한은 **P(여유)** 이고,
  보통·혼잡에 걸리면 0으로 본다. 이 표가 그 근거다.
