한 쪽으로 줄이기

여러 쪽짜리 보고서를 올리면 1쪽 회의자료(한글 파일)로 줄여 줍니다. 한글·워드·엑셀·파워포인트·PDF·그림을 섞어 올려도 됩니다.

이 도구는 다른 앱과 다릅니다

한글 파일을 만들려면 서버가 필요해서, 이 페이지는 들어가는 문일 뿐입니다. 실제 작업은 여러분이 띄운 서버에서 돌아갑니다. 그래서 올린 문서가 이 웹사이트를 거치지 않습니다.

열기
주소를 넣으면 이 브라우저에 기억해 둡니다.

서버 켜는 법

한 번만 준비하면 됩니다. 

pip install -r requirements.txt

그다음 켤 때마다 — 공개 주소가 필요하면: 

python server.py --tunnel --pass 원하는비밀번호

내 PC에서만 쓸 거라면: 

python server.py
  • 터널을 쓰면 ★ 공개 주소: 뒤에 나오는 주소를 위 칸에 넣으세요.
  • 그 주소는 서버를 껐다 켜면 바뀝니다.
  • 밖에 열 때는 비밀번호가 없으면 서버가 뜨지 않습니다.

개인이 만든 실험적인 도구이며 예고 없이 바뀌거나 멈출 수 있습니다. 요약은 AI가 만든 초안이니 보고 전에 사람이 반드시 확인하세요. 개인정보가 담긴 문서를 올릴지는 소속 기관의 규정을 먼저 확인하시기 바랍니다.
