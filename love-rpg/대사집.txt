1장. 포스터 한 장 — 카페 봄날
────────────────────────────────────────────────────────────
  [   ] 어느 봄날 점심시간, 골목 카페 「봄날」. 회사원 민준의 단골 가게다.
  [사장님] 어서 와요. 늘 앉던 창가 자리 비워 놨어요.
  [사장님] 아 참, 우리 알바생이 손님 찾던데? 카운터 쪽으로 가 봐요.
  [민준] (나를? 왜지?)
  [   ] 카운터 앞. 할머니 한 분이 메뉴판을 올려다보고 계신다.
  [서연] 할머니~ 이건 덜 달고요, 이게 지난번에 드신 그거예요. 뜨겁게 해 드릴까요?
  [할머니 손님] 아이고, 우리 아가씨가 내 입맛을 다 기억하네.
  [서연] 단골이신걸요! 자리에 계시면 가져다 드릴게요~
  [민준] (목소리가… 봄 같다. 그리고 할머니께 진짜 다정하다.)
  [할머니 손님] 고마워요. (총총)
  [서연] 어! 저기, 늘 창가에서 노트북 하시는 분 맞죠? 부탁이 하나 있어서요.
  [서연] 사장님이 신메뉴 포스터를 저더러 만들래요… 저 그림엔 진짜 자신 없거든요.
  [민준] (부탁을 받았다!)
        → 맡겨 주세요. 오늘 안에 만들어 드릴게요
        → 어… 일정이 좀…
        → 신메뉴가 뭔데요?
  [서연] 와, 시원시원하다! 감사해요!
  [서연] 아… 바쁘시구나…
  [민준] 농담입니다! 바로 만들게요. (내가 왜 그랬지)
  [서연] 벚꽃 라떼요! 저기 분홍 글씨. 예쁘죠?
  [민준] (이름부터 봄이네.)
  [   ] 늘 앉던 창가 자리로 돌아가 노트북을 열자.
  [민준] 벚꽃 라떼 포스터… 조각부터 바로 세우자.
  [민준] 음, 다시 해 보자. (노트북 자리 앞에서 A)
  [민준] 완성! 이 골목 역대급 포스터다. 보여 주러 가자.
  [민준] 서연 씨, 포스터 완성했어요.
  [서연] 벌써요?! …우와, 예쁘다. 벚꽃잎까지 날려 주셨네!
  [서연] (그림도 잘 그리고, 매일 같은 자리에서 성실하고…)
  [민준] (칭찬받았다. 오늘 커피가 더 달다.)
  [서연] 보답으로 내일 음료는 제가 쏠게요! 사장님 몰래는 아니고요.
  [   ] 이렇게 두 사람의 봄이 시작됐다.

2장. 드론이 나는 날 — 강변 공원
────────────────────────────────────────────────────────────
  [   ] 몇 번의 커피와 몇 번의 수다 끝에, 첫 데이트. 민준이 아끼는 드론을 들고 나왔다.
  [민준] (오늘은… 꼭 멋있는 모습을 보여 준다.)
  [서연] 우와, 이게 그 드론이에요? 진짜 날아요?
  [민준] 그럼요. 강바람쯤은 껌입니다. (사실 조금 긴장된다)
  [서연] 날려 봐요, 날려 봐요!
  [서연] 앗… 그래도 멋있었어요! 한 번 더?
  [서연] 와아아! 진짜 잘 날린다!
  [민준] (됐다. 오늘의 목표 달성.) 서연 씨도 해 볼래요?
  [   ] (서연이 조종간을 잡았다. …의외로 민준보다 잘 날렸다.)
  [서연] 이거 재밌네요! 우리 다음에 또 날려요.
  [민준] (다음이 생겼네.)
  ( 사진 ) 그날의 강변, 그리고 드론
  [   ] 해 질 무렵까지, 두 사람은 강가에서 웃었다.

3장. 우리, 사귈래요? — 민준의 자취방
────────────────────────────────────────────────────────────
  [   ] 데이트를 이어오던 어느 저녁. 오늘은 민준의 자취방에서 영화를 봤다.
  [   ] 영화는 끝났는데, 아무도 리모컨을 잡지 않는다.
  [서연] …영화 재밌었다. 그치?
  [민준] (심장 소리가 들릴 것 같다. 뭐라고 하지?)
        → 서연 씨랑 있으면 시간이 너무 빨라요
        → 라, 라면 먹을래요?
        → (아무 말 없이 눈을 본다)
  [서연] …나도요. 이상하게 안 지겨워.
  [서연] 방금 먹었잖아요. 후후.
  [민준] (바보냐 나는)
  [서연] …왜요. 왜 그렇게 봐요. (귀가 빨개졌다)
  [민준] 서연 씨.
  [서연] …네.
  [민준] 우리… 사귈래요?
  [   ] (아주 짧고, 아주 긴 침묵)
  [서연] …네.
  [   ] 창밖의 봄이 조금 더 환해졌다.

4장. 처음 서운했던 날 — 서연의 원룸
────────────────────────────────────────────────────────────
  [   ] 사귄 지 백 일쯤 된 어느 날, 서연의 원룸. 오늘은 공기가 낮다.
  [   ] (약속에 늦고, 사과가 짧았다. 무슨 일이었는지는… 사실 중요하지 않다.)
  [민준] (달래러 왔다. 그런데 서연 달래기는… 난이도가 높다.)
  [민준] (첫마디가 절반이다)
        → 서연아, 아까는 미안해. 내 말이 짧았어
        → 뭐가 그렇게 서운한데?
        → 떡볶이 시킬까?
  [서연] …흥.
  [서연] 몰라서 물어?
  [서연] 지금 떡볶이가 넘어가?
  [민준] (다음 한마디)
        → 네 입장에서 먼저 생각을 못 했어
        → 나도 나름 바빴거든?
        → 자자, 우리 착하지
  [서연] …그걸 알긴 아네.
  [서연] 지금 그 얘기가 왜 나와.
  [서연] 애 취급하지 마.
  [서연] …됐어.
  [민준] ("됐어"의 번역은?)
        → 안 됐다는 뜻. 더 들을게, 천천히 말해 줘
        → 그래, 그럼 좀 쉬어
        → 알았어, 나 갈게?
  [서연] (조금 풀렸다) …있잖아. 나는 그때…
  [   ] (서연의 이야기를 끝까지 들었다. 중간에 끼어들지 않고.)
  [서연] 쉬라면 진짜 쉰다?
  [서연] …가.
  [민준] (약속의 시간)
        → 다음엔 늦을 것 같으면 미리 전화할게. 약속
        → 내가 다 잘못했어 (영혼 1g)
        → 우리 이제 싸우지 말자!
  [서연] …구체적이네. 좋아, 기억한다?
  [서연] 영혼 없는 거 다 티 나거든.
  [서연] 그게 마음대로 되니?
  [민준] (마무리)
        → (가만히 손을 내민다)
        → 셀카 찍자! 화해 기념
        → 내일 카페 갈까
  [   ] (서연이 잠깐 노려보다가… 손을 잡았다)
  [서연] 분위기 파악.
  [서연] …치. 다음엔 진짜 잘해.
  [민준] 응. (첫 화해, 무사히 완료)
  [   ] 싸우는 법보다 화해하는 법을 먼저 배웠다.
  [서연] …아직이야.
  [민준] (다시. 서두르지 말자. 다시 말 걸어 보자.)

5장. 네 글자 — 바닷가 레스토랑
────────────────────────────────────────────────────────────
  [   ] 이 년 뒤, 바닷가 레스토랑 「첫눈」. 민준이 한 달 전부터 예약한 곳이다.
  [   ] 통유리 너머로 어두운 바다가 반짝인다. 주머니 속 작은 상자가 아까부터 무겁다.
  [민준] (정장이 조금 조인다. 아니, 심장이 조이는 건가.)
  [지배인] 예약하신 창가 자리입니다. …준비는 말씀하신 대로 해 두었습니다.
  [서연] 뭐야, 오늘 왜 이렇게 좋은 데야? 무슨 날이야?
  [민준] (아직 아니다. 침착하자.)
  [지배인] 먼저, 오늘 밤 연주가 있겠습니다.
  ( 미니게임 ) 연주자의 피아노 ♪
  [피아노 연주자] 험, 다시 하겠습니다. 바닷바람 때문입니다.
  [   ] (피아노 소리가 통유리 너머 바다까지 흘러갔다)
  [서연] (뭔가 이상하다. 이 곡… 우리가 처음 같이 들은 노래다.)
  [민준] 서연아. 나 사실… 노래 하나 연습했어.
  [서연] 뭐? 여기서? (주변 테이블이 슬금슬금 쳐다본다)
  ( 미니게임 ) 민준의 세레나데 ♪
  [민준] (헛기침) 마이크 탓입니다. 다시!
  [   ] (노래가 끝나고, 민준이 한쪽 무릎을 꿇었다)
  [서연] …어? 어어?
  [민준] 서연아. 네 글자만 말할게.
  [민준] (상자를 연다)
        → 나랑 결혼해 줄래?
        → …그 네 글자, 알지?
        → (말없이 반지를 내민다)
  [서연] 다섯 글자거든, 바보야. …응. 할래.
  [서연] 알지. …나도 네 글자로 답할게. 「나도 좋아」.
  [서연] (눈물이 그렁그렁) …말로 해 줘. 아니다, 됐어. 응!
  [   ] (박수, 파도 소리, 그리고 두 사람)
  [손님] 축하합니다~!!
  ( 사진 ) 바닷가 레스토랑 — 네 글자의 밤
