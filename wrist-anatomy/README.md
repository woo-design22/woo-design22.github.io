# 오른쪽 손목 · 층별 해부

피부부터 뼈까지 여덟 층을 한 겹씩 벗겨 보는 3D 해부 뷰어입니다.
브라우저에서 파일 하나로 돌아갑니다(외부 라이브러리 없음, `file://` 에서도 동작).

**https://woo-design22.github.io/wrist-anatomy/**

---

## ⚠️ 먼저 읽어 주세요

**교육 참고용입니다. 진료 판단에 쓰지 마세요.**

- **형상**은 Z-Anatomy(BodyParts3D 기반)에서 왔고 공간 관계를 실측으로 검증했습니다.
- **설명 글**은 169개 중 **16개만** 권위 있는 자료와 대조했습니다.
  나머지는 표준 해부학 내용이지만 **아직 출처 대조를 거치지 않았습니다.**
  화면에서 초록색 `✓ 출처` 가 붙은 것과 회색 안내가 붙은 것을 구분해 보여 줍니다.

## 무엇을 볼 수 있나

| | |
|---|---|
| **여덟 층** | 피부·표면 → 근막 → 천부 정맥·피신경 → 힘줄·지지대 → 근육 → 심부 신경·혈관 → 인대·관절낭 → 뼈 |
| **195개 구조** | 손목뼈 8개, 신전건 6구획, TFCC, 정중·척골신경, 요골·척골동맥 등 |
| **검색** | 임상 통용명(주상골)·학회 용어(손배뼈)·영어(scaphoid)·약어(TFCC) 어느 것으로도 |
| **투시** | 찾은 구조만 남기고 나머지를 비쳐 보이게 — 깊은 곳도 바로 확인 |
| **동작 11가지** | 회내·회외·굽힘·젖힘·매달리기·팔굽혀펴기 등에서 부하를 받는 구조를 표시 |
| **움직임** | 뼈를 실제 각도로 회전시켜 동작을 보여 줍니다 |

## 만든 과정

```
Z-Anatomy Startup.blend (293MB)
   ↓ extract.py          손목 7.5cm 반경만 골라 층 분류 → 16비트 양자화
data/wrist.bin (1.8MB)
   ↓ build_app.py        base64 로 index.html 에 심음
index.html (2.6MB)       단일 파일 뷰어 (WebGL2 직접 호출)
```

영상이 필요하면 두 갈래가 있습니다.

- `recv.py` — 뷰어가 그린 프레임을 받아 파일로 저장 (즉시, 정확)
- `render_blender.py` — 같은 카메라 경로로 Blender 고화질 렌더

두 경로의 카메라 식이 같아서 결과를 구간별로 섞어 쓸 수 있습니다.

## 검증

- **구조** — 좌표를 직접 재서 확인했습니다: 오른손 여부, 근위·원위 손목뼈열 배열,
  요측↔척측 순서, 두상골의 장측 위치, **정중신경이 굴곡지대 아래(수근관 안)를 지나는지**,
  요골동맥·척골동맥의 좌우. 10개 항목 통과.
- **설명 글** — `tools_claims.py` 가 주장을 위험도별로 분류합니다.
  대조 과정에서 실제로 오류 3건을 잡았습니다(장장근 결손률의 인구집단 차이,
  교차 증후군의 방향, TFCC 단정 과장).
